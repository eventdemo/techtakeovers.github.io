# Concept
A lightweight, AI-powered web application that translates informal ideas, sentences, and problem descriptions into precise, natural software engineering terminology.
Core features
Translate: Convert everyday language into software engineering language
Choose a dialect: Select the desired tone: Software Engineering, Software Architecture,SRE/DevOps, Executive
Explain terminology: Highlight technical terms and provide definitions from a curated dictionary.
Correct misconceptions: Identify technically inaccurate or ambiguous statements.
Copy results: Easily reuse the translated sentences

## Product philosophy
Not a jargon generator. An engineering communication assistant. The goal isn't to make people sound unnecessarily technical. It's to help them express ideas using accurate software engineering concepts and vocabulary.

## Example

Input: "Our application becomes slow when too many users access it simultaneously."

Output: "The application experiences increased response latency under high request concurrency, potentially due to resource saturation."

Concepts introduced:
    - Latency
    - Concurrency
    - Resource saturation

## MVP scope

Keep the first version simple:
Single text input.
Four translation styles.
AI-generated translation.
Highlighted technical terminology.
Clickable dictionary definitions.
Copy-to-clipboard
